# boot.asm 解释

## 初始化阶段

‌bits 16‌：声明使用 16 位实模式
‌org 0‌：程序加载到内存偏移 0 处
‌start: jmp main‌：跳过 BPB 区域，直接跳转到主程序入口

## BPB 参数块定义

定义 FAT12 文件系统的关键参数：

每扇区 512 字节
每簇 1 个扇区
2 个 FAT 表，每个占 9 个扇区
根目录 224 个条目
总扇区数 2880（1.44MB 软盘）

## 字符串打印功能（Print 例程）

从 DS:SI 读取以 0 结尾的字符串
使用 BIOS 中断 0x10 的 0x0E 功能逐个字符输出
遇到空字符时返回

## 主程序入口

main 函数会：
初始化段寄存器
调用 Print 显示欢迎信息"‌wtOS‌"
调用 ReadSectors 加载更多扇区

## 磁盘读取核心功能

ReadSectors 例程：
‌ 重试机制 ‌：设置 5 次重试计数器
‌ 扇区转换 ‌：调用 LBACHS 将 LBA 转换为 CHS 格式
‌BIOS 读取 ‌：使用 INT 0x13 AH=0x02 读取单个扇区
‌ 错误处理 ‌：读取失败时重置磁盘并重试
‌ 进度显示 ‌：成功读取后显示进度点
LBACHS 转换逻辑：
将逻辑扇区号转换为物理磁盘的柱面-磁头-扇区地址：

‌ 绝对扇区 ‌ = (LBA / 每磁道扇区数) + 1
‌ 绝对磁头 ‌ = (LBA / 每磁道扇区数) MOD 磁头数
‌ 绝对磁道 ‌ = LBA / (每磁道扇区数 × 磁头数)
ClusterLBA 转换：
将 FAT 簇号转换为 LBA 地址：

‌LBA‌ = (簇号 - 2) × 每簇扇区数 + 数据区起始扇区

## 核心功能

‌FAT12 文件系统识别 ‌：通过 BPB 参数让 BIOS 识别磁盘格式
‌ 扇区读取 ‌：能够可靠地读取磁盘数据
‌ 错误恢复 ‌：内置磁盘重置和重试机制
‌ 进度反馈 ‌：提供可视化的加载进度指示

模块化结构：各功能分离，便于维护
健壮性设计：多重错误处理机制
标准兼容：符合 FAT12 和 BIOS 引导规范
